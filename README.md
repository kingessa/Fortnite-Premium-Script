## 🎮 التحكم والأزرار

### أزرار التحكم الأساسية
```
R2 (PS4_R2)          → زر الإطلاق
L2 (PS4_L2)          → زر التصويب المركز (ADS)
L3 (PS4_L3)          → زر الركض
RX / RY              → التحكم بالكاميرا اليمنى
LX / LY              → التحكم بالحركة اليسرى
```

### اختصارات القائمة
```
L2 + Share           → تشغيل/إيقاف السكريبت بالكامل
L2 + Options         → فتح قائمة التعديلات الرئيسية
↑ / ↓                → التنقل بين الأوضاع (MODs)
← / →                → تغيير قيم الخيارات
Cross (X)            → دخول وضع التعديل
Circle (O)           → الخروج من القائمة
R3                   → ضبط Anti-Recoil اليدوي
PS                   → حفظ الإعدادات
```

## 🔧 الأوضاع (MODs) المتاحة

### 1️⃣ HIP ASSIST - مساعدة التصويب من الورك
```
تفعيل/تعطيل: ON/OFF
التحكم:
  - AA Radius (1-99)        → نطاق المساعدة
  - AA Steps (1-99)         → خطوات المساعدة
  - AA Time (1-100)         → وقت المساعدة
  - AA Size (1-100)         → حجم منطقة المساعدة
```
**الاستخدام:** يوفر مساعدة تصويب قوية عند الإطلاق من الورك

### 2️⃣ TRACKING AIM - التصويب بالتتبع
```
تفعيل/تعطيل: ON/OFF
```
**الاستخدام:** تتبع سلس للأعداء مع تأخير زمني محسوب

### 3️⃣ ANTIRECOIL - تقليل الارتداد
```
تفعيل/تعطيل: ON/OFF
التحكم:
  - AR Vertical (1-99)      → تقليل الارتداد الرأسي
  - AR Horizont (-99-99)    → تقليل الارتداد الأفقي
```

### 4️⃣ RAPID FIRE - إطلاق نار متسارع
```
الخيارات:
  0 - Disable       → معطل
  1 - Fire Only     → في وضع الإطلاق فقط
  2 - ADS & Fire    → في وضع التصويب والإطلاق
  3 - ADS Only      → في وضع التصويب فقط

التحكم:
  - RF Hold (1-1000)   → مدة الضغط (ملي ثانية)
  - RF Release (1-1000) → مدة الإفراج (ملي ثانية)
```

### 5️⃣ NO DELAY - بدون تأخير
```
الخيارات:
  0 - Default  → 10ms (افتراضي)
  1 - XBOX ONE → 8ms
  2 - PS5/PS4  → 6ms
  3 - XBOX X/S → 4ms
  4 - PC       → 2ms
  5 - 1 MS     → 1ms
```

### 6️⃣ HAIR TRIGGERS - تحفيزات حساسة
```
تفعيل/تعطيل: ON/OFF
```

## ⚙️ تخصيص القيم

### نطاقات القيم الافتراضية
```
AA Radius        → 10 (نطاق 1-99)
AA Steps         → 15 (نطاق 1-99)
AA Time          → 20 (نطاق 1-100)
AA Size          → 15 (نطاق 1-100)
AR Vertical      → 20 (نطاق 1-99)
AR Horizontal    → 0  (نطاق -99-99)
RF Hold          → 20 (نطاق 1-1000)
RF Release       → 30 (نطاق 1-1000)
```

### طريقة التعديل
1. افتح القائمة: **L2 + Options**
2. اختر الـ MOD المطلوب: **↑ ↓**
3. اضغط **X** للدخول لوضع التعديل
4. تحكم بالقيم: **L2 + ← →** (±1) أو **↑ ↓** (±10)
5. احفظ: **PS** أو اخرج: **Circle**
